This folder contains three images used by your website. You can replace all or some of them:

——— capture.jpg · 300KB max ———

The preview image you see when you paste a link in a message.

——— apple-touch-icon.png · 180x180 px ———

Shortcut icon when the page is saved to the home screen of an iPhone.

——— favicon.ico ———

Icon used in the browser tabs.

This must be a ".ico" file. To create a new one, go to

    realfavicongenerator.net

    600x160px
    PNG image
